## 使用方式

渲染器默认读取仓库内的 `maps/catalog.json`。同一地图在多局出现时复用对应图片，原图保存在 `maps/originals/`，缩略图用于本页展示。

图鉴、社区转载和官方公告转载按索引中的 `source_type` 区分，完整来源、星级、别名和 SHA-256 见 [catalog.json](../maps/catalog.json)。这些是游戏场景及宣传美术素材，保留其原有权利。

## 添加新地图

1. 核实地图属于 QQ 飞车手游，并找到可辨识的场景图。
2. 保存原图与缩略图，按现有记录的结构补充名称、别名、相对路径和实际来源。
3. 核对场景后填写 `status: "verified"` 和原图的 SHA-256，并更新 `expected_count`。
4. 运行 `npm run maps:audit` 检查缺图、重复图和来源字段，再在比分 JSON 中使用地图名。

不要用路线小地图、同名端游图片或生成的相似风景替代实际赛道。亚特兰蒂斯与反向亚特兰蒂斯也应分别登记。
